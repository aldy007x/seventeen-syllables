One haiku about debugging for make.fun's "Seventeen Syllables of Debugging" bounty — three lines in the 5-7-5 syllable shape, at most 200 characters. The entry program validates the haiku (three lines, 5-7-5 syllables, within the character limit) and writes it to `/output/entry.txt`, where the house judge reads it.

> One more print statement
> and the bug moves somewhere else
> it knows I'm watching

## Run it

```sh
python3 main.py
```
